## 🛠 环境与运行

- Python 3.11+
- Jupyter Notebook、Pandas、Matplotlib、NumPy

```bash
python3 -m pip install jupyter pandas matplotlib numpy
jupyter notebook Chapter2
```

两个案例也提供了可直接运行的 Python 脚本：

```bash
python3 "Chapter2/10.TMDB-TOP300电影榜单数据统计.py"
python3 "Chapter2/12.商城销售订单数据统计分析.py"
```

脚本会读取 `Chapter2/data/` 中的 CSV，并将生成的 PNG 图表保存到同一目录。部分图表设置了中文字体，字体效果会随运行系统而变化。
