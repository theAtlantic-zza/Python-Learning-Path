## 🛠 环境

- **Python 3.11+**
- **Jupyter Notebook**（Chapter 2 需要）
- **Pandas**（Chapter 2 需要）

```bash
# 安装最少依赖
pip install jupyter pandas

# 启动 Jupyter 看 Chapter 2
jupyter notebook
```
