## 运行与找回

当前两题使用 Python 3.14.0 和 [requirements.txt](requirements.txt) 中的版本。在 PyCharm 项目虚拟环境的终端，从仓库根目录运行以下命令。

```bash
python -m pip install -r ghostwriting/requirements.txt
python "ghostwriting/双y轴绘制/双y轴绘制.py"
python "ghostwriting/主成分的得分图与载荷图绘制/主成分的得分图与载荷图绘制.py"
```

每个脚本都将图写入自己的 `outputs/`。核对结果时，双 Y 轴图应有五组并列柱形和三条折线。PCA 得分图两轴的方差贡献率应分别为 95.31% 和 3.43%，载荷图显示 PC2。

用户确认验收后，按[仓库约定](../AGENTS.md)清理过程文件并推送。按验收提交找回当时的原题、数据、代码和成品，例如从仓库根目录运行 `git log -- "ghostwriting/双y轴绘制"`。
