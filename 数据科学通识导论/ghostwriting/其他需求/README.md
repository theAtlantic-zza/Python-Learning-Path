# 其他需求

存放接到的、未归属张雨墨、张书源或高欣的零散需求，每个题目独立收纳题目、数据、源码和成品。本目录的两项需求均不属于用户本人的课程作业。

## 双y轴绘制

已验收，只保留基础版。[源码](双y轴绘制/双y轴绘制.py) · [成品图](双y轴绘制/outputs/双y轴绘制.png) · [原题](双y轴绘制/inputs/双y轴绘制_题目.jpeg) · [Excel](双y轴绘制/inputs/origin画图%281%29.xlsx)。

读取 `双Y图` 工作表的五个时间点，三条温度折线对应左轴，两组截光率柱形对应右轴。

## 主成分的得分图与载荷图绘制

已验收。[源码](主成分的得分图与载荷图绘制/主成分的得分图与载荷图绘制.py) · [得分图](主成分的得分图与载荷图绘制/outputs/主成分得分图.png) · [PC2载荷图](主成分的得分图与载荷图绘制/outputs/主成分2载荷图.png) · [预处理说明](主成分的得分图与载荷图绘制/outputs/主成分分析_预处理与结果说明.txt)。

原件：[题目](主成分的得分图与载荷图绘制/inputs/主成分的得分图与载荷图绘制_题目.jpg) · [课件](主成分的得分图与载荷图绘制/inputs/主成分分析%281%29.pdf) · [实际输入](主成分的得分图与载荷图绘制/inputs/作业%281%29.xlsx) · [随题提供的另一份数据](主成分的得分图与载荷图绘制/inputs/作业数据%281%29.xlsx)。

两张图都使用 `作业(1).xlsx` 的45个样本、619个变量进行同一次 PCA。按列均值中心化，保留原始尺度；类别标签只用于分组显示。PC1、PC2贡献率约为95.31%、3.43%。另一份 Excel 仅作为提供的原件保留。

## 运行

在仓库根目录使用现有项目解释器：

```bash
.venv/bin/python "数据科学通识导论/ghostwriting/其他需求/双y轴绘制/双y轴绘制.py"
.venv/bin/python "数据科学通识导论/ghostwriting/其他需求/主成分的得分图与载荷图绘制/主成分的得分图与载荷图绘制.py"
```

数据均从本题的 `inputs/` 读取，图片写入本题的 `outputs/`。依赖版本统一见 [requirements.txt](../../requirements.txt)，历史与验收规则见 [ghostwriting 索引](../README.md)。
