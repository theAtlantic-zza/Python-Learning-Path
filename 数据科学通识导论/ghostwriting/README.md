## 原件、源码与成品

- 共用课件、模板和样例数据见 [课程资料](../inputs/课程资料/)。某道题专属的 Excel、PDF、题目截图放在该题的 `inputs/`。
- `.py` 放在作业或需求目录；HTML、图片等正式结果放在该题的 `outputs/`。提交格式为 Python 时直接提交源码，不额外复制。
- HTML 是代码及一次实际运行结果的快照。后续仅在明确要求时重新导出，目录迁移不触发重导出；随机数题重新运行可以得到不同的数值。
- 全课程使用同一份 [requirements.txt](../requirements.txt)。已验证环境为 Python 3.14.0，代码按课程方法和初学者水平编写，只保留必要注释。
- 桌面课程目录的姓名及“其他需求”入口指向这里的同一份文件，避免维护可分别修改的副本。发送作业时发送实际文件，不发送入口链接。

第三次作业对应第三章 Series、DataFrame 体验和第19、31页练习，各套三个 Python 文件均可独立运行，无外部数据依赖。Series 按题干删除位置1、2、3；DataFrame 最后一步为空表是题目操作的结果。

用户确认指定人员、题目或明确的一批需求验收通过后，按[仓库规则](../../.cursor/rules/task-acceptance.mdc)检查、清理、更新状态、commit、push，并返回提交链接。整理目录不代表其他待验收作业同时通过。

历史通过 Git 查找，不堆积旧版副本。双 Y 轴和主成分分析的历史验收提交见 [fd27772](https://github.com/theAtlantic-zza/Python-Learning-Path/commit/fd2777245cf22405e3f35fe80ba828015d2789db)；目录迁移后用 `git log --follow -- "文件路径"` 跟踪改名历史。课程目录整理和当前已完成作业已于2026-11-09获准提交归档，记录随本次 Git 提交保留。
