## 学习路线

1. **Python 短诊断**：用课件中的成绩表复习列表、索引、循环、函数和平均值计算，确认基础是否熟练。
2. **NumPy 多维数据**：数组的 `shape`、行列索引、布尔筛选、`axis`、广播和随机数；对应第 2 份课件。
3. **Pandas 与统计**：`Series` / `DataFrame`、读写、缺失值、合并、分组、描述统计和相关性；对应第 3 份课件，并联系旧仓库中的订单分析。
4. **数据可视化**：按问题选择图表，使用 Matplotlib 和 Pandas 绘图，检查坐标轴、单位和图例；对应第 4 份课件。
5. **综合练习**：从一个明确问题出发，完成数据检查、清洗、统计、图表和简短结论。

第 1 份课件中的数据、信息、知识与数据分析流程作为各阶段的共同背景。课件里的示例代码会按实际使用的 Python 和库版本核对，再用于运行。

## 运行

在 PyCharm 中运行入口文件 `课堂与练习/run_turtle_patterns.py`。若使用终端，请在仓库根目录执行：

```bash
.venv/bin/python "数据科学通识导论/课堂与练习/run_turtle_patterns.py"
```

本次绘图只需 Python 标准库里的 `turtle`。之前的成绩诊断需要 NumPy；当前项目的 `.venv` 已安装 NumPy、Pandas 和 Matplotlib。
